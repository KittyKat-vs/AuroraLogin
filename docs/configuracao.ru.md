# Конфигурация

`config.yml` лежит в `plugins/AuroraLogin/`. У каждой опции уже есть пояснение в самом файле, так что можно понять, за что отвечает поле, не открывая документацию.

Если вы предпочитаете нажимать, а не править текст, `/auroraauth panel` делает то же самое прямо в игре: любая настройка, сохранённая там, попадает в файл сразу — без перезапуска сервера. А поскольку меню переписывает только строку изменившегося значения, комментарии после этого остаются на месте.

Сервер, который уже работал со старым конфигом, обновляется сам при первом запуске после смены версии: плагин переносит ваши значения, сохраняет прежний файл как `config.yml.bak` и пишет новый, прокомментированный. Комментарии намеренно идут на португальском и без диакритики — так файл корректно открывается в любом редакторе, включая те, что сохраняют в ANSI. А вот текст, который видит игрок, как раз с ударениями, и он лежит в файлах папки `lang/`.

## Файл целиком

Ниже — тот же файл, но с переведёнными комментариями, чтобы читать было удобно, не переключая окна. Одно предупреждение: файл, который плагин реально создаёт в `plugins/AuroraLogin/`, оставляет эти комментарии на португальском, потому что шаблон внутри jar один, — так что отсюда копируют значения, а не блок целиком.

```yaml
# ============================================================
#  AuroraLogin - файл настройки
# ============================================================
#
#  Всё, что плагин делает на вашем сервере, собрано здесь.
#  Можно править руками или открыть игровое меню командой
#  /auroraauth panel и просто нажимать на опции.
#
#  Поправили этот файл? Выполните /auroraauth reload — сервер
#  перезапускать не нужно.
#
#  Когда меню меняет опцию, плагин переписывает только строку
#  этого значения. Поэтому комментарии и порядок разделов после
#  этого остаются на месте.
#
#  На сервере эти комментарии выводятся на португальском и без
#  диакритики: шаблон внутри jar один, и так файл корректно
#  открывается в любом редакторе, включая сохраняющие в ANSI.
#  А текст, который видит игрок, как раз с ударениями, — он в
#  файлах папки lang/.
#
#  Сайт, поддержка и подробное объяснение каждой опции:
#  https://auroraplugins.duckdns.org
# ============================================================

# Версия этого формата. Нужна, чтобы после обновления плагин
# понял, что старому файлу пора получить новые комментарии.
# Оставьте как есть.
config-version: 1

# ------------------------------------------------------------
#  Вход и аккаунт
# ------------------------------------------------------------
settings:
  # Язык всего сервера: сообщения, меню и даже названия команд
  # входа. При переходе на en /registrar становится /register,
  # а /entrar — /login. Варианты: pt_br, en, ru.
  default-language: pt_br

  # Лицензионный аккаунт Minecraft заходит сам — без регистрации
  # и без пароля. Выключите, если хотите пароль для всех, включая
  # тех, кто игру купил.
  premium-auto-login: true

  # С включённым плагин проверяет аккаунт у Mojang прямо во
  # время входа — именно это делает авто-вход рабочим на сервере
  # с online-mode=false. Обычно сюда не заглядывают: если
  # проверку делает прокси, она выключается сама.
  premium-verification: true

  # Действует только с установленным Floodgate. С ним игрок с
  # телефона, консоли и Windows заходит без пароля. Без Floodgate
  # опция просто стоит на месте, и bedrock регистрируется с
  # паролем, как все.
  floodgate-auto-login: true

  # Сессия по IP: кто уже входил по этому IP, заходит сразу, без
  # повторного пароля. Игроку это удобно, а вот на сервере в
  # компьютерном клубе — плохо, там у всех один IP.
  session-enabled: true

  # Сколько живёт сессия, в минутах. Прошло — пароль спросят
  # заново.
  session-minutes: 30

  # Время в секундах, за которое игрок должен авторизоваться
  # после захода. Не успел — его отключает.
  timeout-seconds: 60

  # Размер пароля — действует и при регистрации, и при смене.
  password-min-length: 6
  password-max-length: 64

  # Не разрешает ставить паролем собственный ник — это первое,
  # что пробует тот, кто лезет в чужой аккаунт.
  password-deny-name: true

  # При смене пароля не разрешает вернуться к прежнему.
  password-reuse: true

  # Игрок пошёл ходить до входа? Его возвращает на точку захода.
  # Выключите, если предпочитаете оставить его там, где он стоит.
  teleport-on-move: true

  # До авторизации игрок не открывает инвентарь, не ломает и не
  # ставит блоки, не использует предметы и сущности. Это защита
  # от того, кто зайдёт в чужой аккаунт и сразу унесёт сундук.
  block-interactions: true

  # Эффекты на тех, кто ещё не авторизован, — чтобы человек
  # понял, что ждёт входа, а не что сервер завис. Каждый
  # включается и выключается отдельно.
  pre-login-effects:
    # Общая кнопка: выключить её — и ни один эффект не наложится.
    enabled: true
    # Ослепляет игрока.
    blindness: true
    # Замедляет ходьбу.
    slowness: true
    # Уровень замедления, от 1 до 5.
    slowness-level: 2
    # Блоки ломаются дольше.
    mining-fatigue: true
    # Уровень усталости шахты, от 1 до 5.
    mining-fatigue-level: 1

# ------------------------------------------------------------
#  Безопасность
# ------------------------------------------------------------
security:
  # Защита от тех, кто перебирает пароли по одному. Блокировка
  # идёт по IP и усиливается с каждым превышением: первый раз —
  # короткий кик, второй — подлиннее, третий — бан IP.
  brute-force:
    # Общая кнопка защиты.
    enabled: true
    # Сколько неверных паролей может прислать IP внутри окна
    # ниже, прежде чем получит первый страйк.
    max-attempts: 5
    # Окно подсчёта, в минутах.
    window-minutes: 5
    # Длина кика при первом превышении, в минутах.
    block-minutes: 5
    # Длина кика при втором превышении, в минутах.
    second-kick-minutes: 15
    # Длительность бана IP при третьем превышении, в часах. Бан
    # снимается сам по истечении срока — разбанивать никто не
    # должен.
    ban-hours: 24
    # Прошло столько времени без превышений — страйки IP
    # обнуляются. В часах (168 = неделя).
    strike-reset-hours: 168
    # Если выключить, третий раз превращается в очередной кик со
    # вторым временем вместо бана IP.
    ip-ban: true
    # Ссылка-приглашение в Discord, её показывают на экране бана,
    # чтобы игроку было куда пойти. Оставьте пустой (''), чтобы
    # не показывать кнопку вовсе.
    discord-invite: ''

# ------------------------------------------------------------
#  Интерфейс
# ------------------------------------------------------------
visual:
  # Титр на экране при заходе и при авторизации.
  titles: true
  # Звуки на регистрацию, вход и смену пароля.
  sounds: true
  # Экшн-бар с оставшимся временем на авторизацию.
  action-bar: true
  # Как часто обновляется эта строка, в тиках (20 тиков = 1
  # секунда). 40 — значит каждые 2 секунды.
  action-bar-interval-ticks: 40

# ------------------------------------------------------------
#  Меню
# ------------------------------------------------------------
panel:
  # Щелчок при навигации по /auroraauth panel.
  sounds: true

# ------------------------------------------------------------
#  Администрирование
# ------------------------------------------------------------
admin:
  # Пишет в audit.log, что делала администрация: кто сбросил
  # пароль, удалил аккаунт, отключил игрока или разбанил IP.
  # Пароли туда не попадают никогда.
  audit: true

# ------------------------------------------------------------
#  Хранилище
# ------------------------------------------------------------
storage:
  # База SQLite внутри plugins/AuroraLogin/, где лежат аккаунты,
  # сессии и забаненные IP. Для резервной копии скопируйте этот
  # файл на остановленном сервере.
  file: accounts.db
```

## Вход и аккаунт

`default-language` выбирает язык всего сервера: сообщения, меню и даже названия команд авторизации. При переходе на английский `/registrar` становится `/register`, а `/entrar` — `/login`; старые названия тут же перестают существовать.

`premium-auto-login` — это авто-вход лицензионных аккаунтов Minecraft: игрок заходит, плагин проверяет аккаунт и открывает дверь без регистрации и пароля. `premium-verification` — сама проверка, именно она делает авто-вход рабочим на сервере с `online-mode=false`; если у вас Velocity или BungeeCord проверяет сам, плагин это замечает и отключает проверку, но можно выключить её и руками. `floodgate-auto-login` — то же самое для заходящих через Bedrock, и действует только при установленном Floodgate.

`session-enabled` вместе с `session-minutes` разрешают игроку возвращаться по тому же IP, не вводя пароль заново, пока сессия не истекла. `timeout-seconds` — сколько времени у него на авторизацию после захода, прежде чем его отключат.

Четыре поля пароля (`password-min-length`, `password-max-length`, `password-deny-name`, `password-reuse`) задают политику: длина, запрет пароля совпадающего с ником и запрет возвращать прежний пароль при смене.

`teleport-on-move` возвращает игрока на точку захода, если он пошёл ходить до авторизации. `block-interactions` — это то, что не даёт трогать инвентарь, ломать блоки и использовать предметы в этот момент. А `pre-login-effects` накладывает слепоту, замедление и усталость шахты на того, кто ещё ждёт входа, чтобы человек понял, что его держат, а не что сервер завис; уровни от 1 до 5, и каждый эффект включается отдельно.

## Безопасность

Защита от подбора работает по IP и усиливается шагами. `max-attempts` — сколько неверных паролей помещается внутри `window-minutes`; как только лимит превышен, IP получает первый страйк и его кикает на `block-minutes`. Второй страйк кикает на `second-kick-minutes`. Третий даёт бан IP на `ban-hours`, пока включён `ip-ban`; если его выключить, третий раз превращается в очередной кик со вторым временем. `strike-reset-hours` — сколько времени IP должен пробыть без превышений, чтобы страйки обнулились.

Бан снимается сам по истечении `ban-hours`, и он не удаляет ни аккаунты, ни пароли: человек снова сможет играть, когда пройдёт время или когда вы его разбаните. Разбанить раньше — путь через **Безопасность → Забаненные IP** в меню: там список с числом попыток, датой бана, сроком, остатком и причиной по каждому IP.

`discord-invite` принимает ссылку на ваш Discord. Она показывается на экране бана рядом с IP и оставшимся временем, чтобы игроку было куда пойти. Оставьте `''`, чтобы не показывать кнопку вовсе.

## Интерфейс, меню и администрирование

`visual.titles`, `visual.sounds` и `visual.action-bar` отвечают за то, что появляется на экране: титр при заходе и при авторизации, звуки действий входа и экшн-бар с оставшимся временем. `action-bar-interval-ticks` — как часто обновляется эта строка, в тиках, где 20 тиков — одна секунда.

`panel.sounds` включает и выключает щелчок при навигации по меню. `admin.audit` пишет действия администраторов в `plugins/AuroraLogin/audit.log`: кто сбросил пароль, удалил аккаунт, отключил игрока или разбанил IP. Пароли туда не попадают никогда.

## Хранилище

`storage.file` — база SQLite внутри `plugins/AuroraLogin/`, где лежат аккаунты, сессии и забаненные IP. Для резервной копии достаточно скопировать этот файл на остановленном сервере.

## Файлы языков

Тексты сообщений — в `plugins/AuroraLogin/lang/`, по файлу на язык: `pt_br.yml`, `en.yml` и `ru.yml`. Правьте их как хотите, включая названия команд авторизации — они живут в ключах `command-register`, `command-login`, `command-logout` и `command-changepassword`. После правки выполните `/auroraauth reload`, чтобы применить.
